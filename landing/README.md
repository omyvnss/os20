# OS20 website

Static one-page site. No build step.

```bash
cd landing
python3 -m http.server 3020 --bind 127.0.0.1
```

Open http://localhost:3020. The app itself runs separately at http://localhost:3010.

`img/` holds real OS20 screenshots (1440x900 at 2x) taken from a fresh install with sample companies.
